# GitHub Issues Demonstration

This file is for demonstrating how a project change can be committed and pushed to GitHub.

## Sample project concerns

### 1. Bug report: Login button is not responding
**Type:** Bug

**Description:** The login button does not respond after a user enters a valid username and password.

**Expected result:** The user should be redirected to the dashboard after successful login.

### 2. Feature request: Add a search function
**Type:** Enhancement

**Description:** Add a search feature so users can quickly find specific records.

### 3. Task: Improve the dashboard interface
**Type:** Task

**Description:** Improve the dashboard layout to make the system easier to navigate.

---

**Note:** These are demonstration examples only. To make them appear on the GitHub Issues page, create them separately using the repository's **Issues → New issue** button. Pushing this file will add it to the repository, but will not automatically create GitHub Issues.
